# Intent

One command answers the operator's question "did this restoration actually turn
out good?" for one album, reproducibly and honestly: the restored album is
measured against its own source with the same instrument used everywhere else,
the verdict procedure is fixed before the data, and the report separates what
the metrics prove (output constraints, dynamics change, systematic shifts) from
what they cannot prove (listening preference).

# Given

- `scripts/audio_measure.py::analyse()` — DR (TT), crest, LUFS/TP (ffmpeg
  ebur128, whole file), int16 clipping; the measurement source of truth.
- `scripts/eval_vs_masters.measure_file` — the same values plus
  `spikes_over_09` (samples with |x| > 0.9 in the first ~90 s of a
  native-channel decode) and the 1/3-octave band vector.
- A restored album directory produced by `scripts/restore_safe.py`, optionally
  with `report.json` (per-track rows with `status`, `needs_review`,
  `restoration_state`); its statuses are lifted into the verdicts, never
  invented.
- Repo conventions: plain `python3`, numpy only, tests offline via
  `python3 -m pytest`.

# When

The operator runs the CLI over a source/restored directory pair.

# Then

## 1. `scripts/evaluate_album.py`

```
python3 scripts/evaluate_album.py --src <original-dir> --restored <restored-dir> \
        --out <dir> [--tp-ceiling -0.9] [--dr-threshold 0.3] [--loudness-mismatch-lu 2.0]
```

Required public names (imported by the oracle):

- `normalize_name(stem) -> str` — lowercased, parenthesized segments removed,
  non-alphanumeric runs collapsed to single spaces.
- `match_tracks(src_files, res_files) -> (matched, skipped)` — matched:
  list of `(label, src_path, res_path, via)` with `via` in `{"number",
  "name"}`; skipped: list of `{"track", "side", "reason"}` where reason is
  `track_mismatch` or `ambiguous_name_match`.
- `track_verdict(ours, orig, tp_ceiling=-0.9, dr_threshold=0.3,
  loudness_mismatch_lu=2.0) -> (verdict, reason, comparability)` — verdict in
  `ours_better | orig_better | comparable`, reason in
  `ceiling | dr | spikes | tie`, comparability in `loudness_mismatch | ok`:
  1. `ours["true_peak_db"] > tp_ceiling` → `orig_better/ceiling` (our output
     violated the ceiling; the original is not judged by it);
  2. DR gap ≥ threshold → higher DR wins, `reason=dr`;
  3. otherwise spike count → fewer wins, `reason=spikes`;
  4. otherwise `comparable/tie`.
  comparability: `|ours.lufs − orig.lufs| > loudness_mismatch_lu` →
  `loudness_mismatch`, else `ok`.
- `album_verdict(verdicts) -> (verdict, reason)` — majority vote
  (`ours_better` vs `orig_better`), `inconclusive/tie` when only
  `inconclusive` remains, else `comparable/tie`.

## 2. Outputs in `--out-dir` (all or nothing)

| file | required columns / keys |
|---|---|
| `tracks.csv` | `track, dr14_orig, dr14_ours, crest_db_orig, crest_db_ours, lufs_orig, lufs_ours, true_peak_db_orig, true_peak_db_ours, clip_samples_orig, clip_samples_ours, spikes_over_09_orig, spikes_over_09_ours, band_shift_db, band_delta_mean_db, punch_retention_db` |
| `verdicts.csv` | `track, verdict, reason, comparability, status, needs_review, restoration_state` |
| `summary.json` | `src, restored, tp_ceiling, dr_threshold, tracks_measured, matched_via{name,number}, skipped, verdict_counts, verdict_overall, verdict_reason, comparability_counts, status_counts, needs_review, systematics, limitations` |
| `REPORT.md` | headings `## Verdict`, `## Systematics`, `## Per track`, `## Limitations` |

`band_shift_db` is the signed mean band delta (ours − orig) — a tonal-shift
indicator, reported as information; `band_delta_mean_db` is its absolute
counterpart.  `punch_retention_db` is `crest_ours − crest_orig`: crest is
scale-invariant, so this is crest at matched loudness, and sample-jump counts
are headroom information (the verdict fails only on growth versus the source).
`systematics` must include: `lufs_gap_median`,
`dr_change_median`, `crest_change_median`, `band_shift_db_mean`,
`punch_retention_median`, `tp_at_ceiling`, `dr_regression_tracks`,
`clipped_orig_sum`, `clipped_ours_sum`, `spikes_orig_sum`, `spikes_ours_sum`.
Statuses come from
`report.json` when present, otherwise `status="unknown"`.  `limitations` states
the measurement window and the proxy character of the metrics.

## Forbidden

- A second implementation of DR/LUFS/crest/clipping/spike/band math, or
  modifying `audio_measure.py`, `eval_vs_masters.py`, `restore_safe.py`,
  `rnext/**` for this task.
- Zero-filling or silently dropping a track that exists on only one side.
- Folding LUFS into the verdict vote.
- Hand-written numbers in the report: every value is rendered from the
  measured data.
- Writing anything outside `--out-dir`.
