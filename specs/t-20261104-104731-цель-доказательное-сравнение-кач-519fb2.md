# Intent

Получить сравнение качества реставрации, которое нельзя опровергнуть круговой
ссылкой на себя же: рядом с каноническим результатом (OURS) должен стоять
результат **независимого** метода (INDEP), полученный кодом, который не
использует `scripts/restore_per_track.py`, `rnext.dsp.pipeline` и его
параметры. Все три версии (ORIG, OURS, INDEP) измеряются одним нейтральным
инструментом, вердикт выводится по заранее объявленной процедуре, а не по
впечатлению. Анализ — по skill `logika`: критерии объявлены до вердикта,
у каждого вывода есть источник-цифра, у каждого сильного утверждения —
контрпример или явное «сравнение неполное».

Состав работ: три скрипта в `scripts/experiment/`, машиночитаемые данные и
отчёт в `docs/`, один документ о методе. Конвейер (`rnext/`, `scripts/*.py`
верхнего уровня) не трогаем.

# Given

- Канон OURS уже лежит в `/media/mydum/Data/Music/<album> [restored per-track]`.
  Скрипт его только читает: ни перезаписи, ни переименования.
- Оригиналы-источники: `/media/mydum/Data/Music/restore/release_src` по авторам
  City and Colour (7), Jelusick (3 + Dino Jelusick Chosen Gems), Perfect Plan
  (3 + JP), Lost Society (1), Papa Roach (1), Whom Gods Destroy (1),
  Ross The Boss (1). Источники read-only по смыслу задачи.
- Измеритель уже есть и работает: `scripts/audio_measure.py` (`analyse()`,
  CLI `--json`, `--quick`). Его не переписываем и не дублируем.
- Свободно ~11G; прогон по всем альбомам в 24-bit WAV не влезает, поэтому
  обработка идёт по одному треку с немедленным удалением временных файлов.

# When

1. `select_albums.py` выбирает до 5 случайных альбомов на автора (меньше —
   все) по сиду и пишет `manifest.json`.
2. `ref_restore.py` реставрирует выбранные оригиналы независимым методом в
   `out`-каталог, по одному треку, с удалением своего `--work-dir`.
3. `compare_restore.py` измеряет ORIG / OURS / INDEP и пишет
   `tracks.csv`, `albums.csv`, `verdicts.csv`, `album_verdicts.csv`,
   `summary.json`, `tables.md`.
4. Агент сводит таблицы и вердикты в
   `docs/experiment-independent-restore-2026-11-04.md` по структуре из Then.

# Then

## 1. `scripts/experiment/select_albums.py`

```
python3 scripts/experiment/select_albums.py --src <root> --per-artist 5 \
        --seed <int> --out <manifest.json>
```

- Альбом = каталог верхнего уровня `<root>`; `artist` — часть имени до ` - `,
  `album` — остальное имя целиком (`Artist - Album (2026)`).
- На каждого автора: `min(--per-artist, доступно)`, выбор через
  `random.Random(seed)` по отсортированному списку — одинаковый сид даёт
  побайтово одинаковый файл (никаких таймстампов).
- Схема манифеста ровно такая: `{"src": <abs>, "per_artist": <int>,
  "seed": <int>, "albums": [{"artist", "album", "rel_path", "n_tracks"}]}`.
- Каталог без аудиофайлов, нечитаемый путь, `--per-artist` < 1 → выход с
  ненулевым кодом и явным сообщением, без «пустого» манифеста.

## 2. `scripts/experiment/ref_restore.py`

```
python3 scripts/experiment/ref_restore.py --src <root> --out <dir> \
        [--work-dir <dir>] [--jobs N]
```

Независимый метод (реализация на выбор, но все ступени видны в коде и в
`docs/experiment/independent-method.md`):

1. деклиппинг перегруженных участков (мягкое восстановление пиков / локальный
   контраст или `sox`/`ffmpeg`-эквивалент), без `rnext.dsp.pipeline`;
2. мягкая нормализация к `-14 LUFS` (integrated, ffmpeg `ebur128`/`loudnorm`);
3. true-peak лимитер на `-1.0 dBFS`;
4. выход — FLAC 24 bit, та же частота дискретизации, те же длительность и
   названия; raw/временные WAV — только в `--work-dir`.

Требования, проверяемые оракулом:

- `src` байт-идентичен до и после; хэши сравниваются по всему дереву.
- На каждый входной аудиофайл — один выход: `out/<rel_dir>/<stem>.flac`.
- `--work-dir` (по умолчанию `<out>/.work`) удаляется по завершении, в том
  числе при падении на треке.
- Guardrails до первой записи: `out` внутри `src`, `out` совпадает с `src`,
  `out` содержит маркер `[restored` (канон), `out` внутри
  `/media/mydum/Data/Music` без маркера `experiment` → отказ, код возврата
  ≠ 0, каталог не создаётся.
- Отсутствие `ffmpeg`/`flac`, неразборчивый файл, ошибка кодирования →
  ненулевой код и явная ошибка с именем трека. Никаких «пропустим и поедем».
- Повторный прогон на тех же входах даёт те же метрики (DR, crest, LUFS, peak,
  clipped) с точностью 0.01.

Запрещено: импорт `restore_per_track`, `rnext.dsp.pipeline`, `Policy`,
`restore_track`.

## 3. `scripts/experiment/compare_restore.py`

```
python3 scripts/experiment/compare_restore.py --src <root> --ours <dir> \
        --indep <dir> --out-dir <dir>
```

- Альбомы и треки берутся из `--src` (та же схема каталогов, что у
  `select_albums.py`); `--ours` и `--indep` зеркалят структуру альбомов.
- Ключ трека `track` = путь файла внутри каталога альбома без суффикса
  контейнера (для плоского альбома это просто stem, для `CD1/01 - x.flac` —
  `CD1/01 - x`). Counterpart ищется по (альбом, этот ключ), суффикс не важен.
  Ровно одно совпадение обязательно; иначе выход с кодом ≠ 0 и перечислением
  отсутствующих/неоднозначных, а `tracks.csv` не пишется вообще.
- Метрики считаются **через** `scripts/audio_measure.py::analyse()` (импорт
  по пути `scripts/`), плюс `spikes_gt_0_9` (число сэмплов с |x| > 0.9 при
  float-декодировании) и `band_delta_max_db` (максимальное по 8 полосам
  отклонение `rnext.features.band_rms_db` от ORIG; у ORIG ровно 0).
- `tracks.csv`, колонки строго в этом порядке:
  `album,track,variant,rel_path,dr,dr_exact,crest_tt,lufs_i,tp_dbfs,peak_dbfs,rms_db,clipped_samples,clipped_pct,spikes_gt_0_9,band_delta_max_db,cutoff_hz,hf_floor_db,sr,bits,dur_s`.
  Сортировка по `(album, track, variant)`, `variant` ∈ {indep, orig, ours},
  дублей ключа нет. Пустая метрика допустима только у `lufs_i`/`tp_dbfs`,
  когда `ebur128` не дал значения; остальные обязаны быть числами.
- `albums.csv`: `album,artist,variant,n_tracks,dr_median,crest_median,lufs_median,tp_max,clipped_pct_sum,spikes_gt_0_9_sum,band_delta_max_db`.
- `verdicts.csv`: `album,track,verdict,reason,comparability`, ровно одна
  строка на (album, track).
- `album_verdicts.csv`: `album,artist,verdict,reason,comparability`, ровно
  одна строка на альбом.
- `summary.json`: минимум `{"variants", "albums", "tracks"}`.
- `tables.md`: markdown-таблицы с заголовками `## Per-track`, `## Per-album`,
  `## Verdicts`. Прозаические разделы пишет агент в отчёт, не скрипт.

Процедура вердикта (объявлена до данных, реализуется ровно так):

Для трека, где `ours` и `indep` — строки `tracks.csv` (значения берутся уже
округлённые, как в CSV):

1. дисквалификация: `tp_dbfs > -0.9` (и `tp_dbfs` известен). Оба
   дисквалифицированы → `inconclusive`/`ceiling`; только OURS →
   `indep_better`/`ceiling`; только INDEP → `ours_better`/`ceiling`;
2. иначе `|dr_ours − dr_indep| ≥ 0.3` → побеждает больший DR, `reason=dr`;
3. иначе различие `spikes_gt_0_9` → побеждает меньший, `reason=spikes`;
4. иначе `comparable`/`tie`.

`comparability`: `unknown`, если `lufs_i` хотя бы у одного отсутствует;
`loudness_mismatch`, если `|lufs_ours − lufs_indep| > 2.0`; иначе `ok`.

Альбомный вердикт — голосование по трековым: больше `ours_better` →
`ours_better`/`majority`; больше `indep_better` → `indep_better`/`majority`;
равенство при наличии `inconclusive` → `inconclusive`/`tie`; иначе
`comparable`/`tie`. `comparability` альбома — по `lufs_median` из
`albums.csv` с тем же порогом 2.0 LU.

- Временные файлы: после прогона в `--work-dir` и в `out` не остаётся

## 6. `docs/experiment-independent-restore-2026-11-04.md`

Обязательные разделы (порядок любой, заголовки дословно):

- `## Criteria` — таблица метрик с направлением («больше = лучше»,
  «меньше = лучше», «направления нет, только для полноты») и порогами из
  процедуры вердикта. LUFS объявлен метрикой сравнимости, а не качества.
- `## Per-track` — таблица по каждому треку (orig / ours / indep: DR,
  crest, LUFS, TP, spikes, clipped, band_delta).
- `## Per-album` — та же тройка по альбомам.
- `## Verdict` — вердикты из `album_verdicts.csv`, с числом треков на каждый
  исход и явным «насколько сравнимы» (в т.ч. `loudness_mismatch`).
- `## Counterexamples` — минимум один трек/альбом, где данные противоречат
  общему выводу или где вывод неустойчив (например DR вырос, но вырос и
  `band_delta_max_db`), и как это меняет формулировку.
- `## Reproducibility` — дословные команды с путями и сидом.
- `## Limitations` — что сравнение не доказывает: разная целевая громкость,
  разные входные форматы, отсутствие слепого прослушивания, OURS и INDEP не
  независимы по источнику (только по методу).

Каждый альбом из `albums.csv` упомянут в тексте. Слово `TODO` и заглушки
запрещены; каждое утверждение «лучше/хуже» привязано к строке данных.
