# Intent

The first eval against master restorations (docs/eval-vs-masters-run.md) found
systematic, fixable deviations: our true peak is pinned to one ceiling for all
material, the dynamics target is a per-track constant that simultaneously
undershoots (Judas Priest) and overshoots (Junkie XL), release loudness drifts,
and `spikes_over_09` was framed as a defect while masters legitimately keep
more hot transients. This task makes the output constraints and the dynamics
target material- and release-aware, adds an opt-in release loudness pass, and
reframes punch as information.

# Given

- `rnext/dsp/selection.py::material_plan/candidate_policies/output_violations`
  — the conservative selection (full-track QC per t-20261104-104731 and
  edbb077's full-context redesign).
- `scripts/restore_safe.py` — the runner: strict decode, encoded QC, fallback
  to source copy; `report.json` rows consumed by `evaluate_album`.
- `scripts/qc_gates.py` — the independent delivery audit.
- `scripts/evaluate_album.py` — the album evaluator (t-20261114-225449).
- `scripts/audio_measure.py::lufs_tp` — ffmpeg ebur128 LUFS/TP, whole file.

# When

The runner processes a directory (release) or a single track; qc_gates audits
deliverables; evaluate_album reads the results.

# Then

## 1. Material-dependent true-peak ceiling (`rnext/dsp/selection.py`)

- `material_plan` returns `tp_ceiling` per class: `sparse → −1.5`,
  `crushed → −0.3`, `mid → −0.5`; `healthy`/`short_or_silent` → `None`
  (identity candidates carry no output constraint).
- `candidate_policies(plan)` builds the base policy with
  `target_tp_dbfs=plan["tp_ceiling"]` (fallback −1.0 when the key is absent).
- `output_violations` takes `tp_ceiling` (default −1.0, tolerance +0.05) and
  reports `true_peak_above_ceiling`; every call site passes the plan ceiling.

## 2. Release-level dynamics target

- `release_target(measures) -> float | None`: median DR of the least-compressed
  third minus the release median; `None` when the spread is < 0.5 (uniform
  release) or fewer than 3 tracks; otherwise clamped to [0.8, 5.3].
- `material_plan(..., release_target=None)` uses it for `crushed`/`mid`
  classes instead of the 5.3/2.3 constants.
- `select_restoration(..., release_target=None)` threads it into
  `select_track`; `restore_safe` computes it once per directory run (strict
  decode + measure per source) and records `release_target` in every report
  row (absent for single-file runs and `None`).

## 3. Opt-in release loudness pass and LUFS window

- `restore_safe --loudness-target LUFS`: after an accepted candidate passes
  encoded QC, measure the encoded file's LUFS; when |target − measured| > 0.2
  LU, apply that gain under the SAME plan true-peak ceiling (limiter, never a
  boost past the ceiling), rewrite, and re-run the FULL encoded QC; any
  violation falls back to the source copy exactly like a candidate failure.
  `report["loudness_plan"]` records measured/target/gain; a failed pass sets
  `qc_fallback_original` + `encoded_candidate_rejected` + `needs_review`.
- `qc_gates --lufs-window LO:HI`: parse the window, measure LUFS
  (`audio_measure.lufs_tp`), add `lufs_i`/`lufs_window` to the JSON record;
  LUFS outside the window (or unmeasurable) is a FAIL. Without the flag the
  gate is unchanged.

## 4. Punch retention in `evaluate_album` (spec t-20261114-225449 amended)

- `tracks.csv` gains `punch_retention_db` = crest_ours − crest_orig (crest is
  scale-invariant: this is crest at matched loudness).
- `summary.json.systematics` gains `punch_retention_median`; `limitations`
  state that sample-jump counts are headroom information (the verdict fails
  only on growth) and that masters legitimately keep hotter transients.
- `REPORT.md` Systematics reports punch retention when |median| ≥ 1 dB.

# Forbidden

- Boosting true peak toward the ceiling for quiet/sparse material, or any
  automatic loudness increase without the explicit `--loudness-target`.
- A loudness pass that skips the re-QC, or ships after violations.
- Changing `audio_measure.py`, `rnext/dsp/pipeline.py` defaults, or the
  declared verdict ladder of evaluate_album.
- Silent behavior changes: without `--loudness-target` and `--lufs-window`
  the runner and the gate must behave exactly as before the task.
- Zero-filling or fabricating LUFS when ffmpeg cannot measure it.
