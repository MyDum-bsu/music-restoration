# music-restoration

Снять «войну громкости» со своей музыкальной библиотеки: задавленные мастера DR4–6 вернуть к здоровым DR8–12, не тронув тембр. Пайплайн реставрации динамического диапазона с обязательной проверкой каждого шага, плюс уход за библиотекой — тексты, обложки, теги, DR-сканирование. Работает с локальными папками и с Android-телефоном по MTP.

Основа — профессиональная цепочка реставрации, восстановленная по отпечатку референсных обработок и собранная из свободного софта: ffmpeg, numpy/scipy и бесплатные функции командной строки Stereo Tool. Инструмент обкатан на библиотеке в ~3000 файлов; каждый альбом перед записью проходит проверку целостности, тегов, обложки и длительности, а после записи — побайтовую сверку по md5.

Работать можно двумя способами.

1. **С ИИ-агентом.** `./install.sh` ставит четыре агентских скилла (`restore-dr`, `add-lyrics`, `phone-music`, `split-flac-album`); дальше просто попросите агента: «реставрируй этот альбом», «добавь тексты в эту папку», «проверь телефонную библиотеку».
2. **Вручную.** Обычные скрипты с понятным CLI:

```bash
# диагноз задавленного мастера, затем реставрация трека
python3 restore-dr/scripts/diagnose.py album/*.flac
python3 restore-dr/scripts/master.py track in.flac out.flac

# одна команда на альбом: реставрация, обложки, теги, проверка, заливка на телефон
python3 restore-dr/scripts/restore_batch.py "Исполнитель - Альбом" --lyrics --mb

# метрики в терминологии dr.loudness-war.info и графики до/после
python3 restore-dr/scripts/measure.py compare in.flac out.flac --outdir report
python3 restore-dr/scripts/scan_dr.py            # DR-скан всей библиотеки
```

Папку музыки на телефоне скрипты находят сами (gvfs MTP), локальная библиотека по умолчанию `~/Music`, рабочие файлы складываются в `~/.local/state/music-restoration/`. Всё переопределяется через `~/.config/music-restoration/config.env` или переменные окружения.

## Платформы

| Задача | Windows / macOS | Linux |
|---|---|---|
| Реставрация: diagnose, master, measure, scan_dr, restore_batch `--out-local` | работает | работает |
| Заливка на телефон по MTP, скилл phone-music | нет (нужен gvfs; под WSL тоже нет) | работает |
| split-flac-album (shntool/cuetag) | сборки существуют, но капризны | работает |

Зависимости: Python 3.10+ и `pip install -r requirements.txt`, пакеты `ffmpeg`, `flac` (вместе с ним ставится `metaflac`), `curl`. Треклисты MusicBrainz и обложки Cover Art Archive ходят через curl — в Windows 10+ он встроен. install.sh написан на bash: под Windows те же шаги делаются руками — своими или руками агента (перечень шагов есть в SKILL.md каждого скилла).

## Установка

```bash
git clone <этот репозиторий> && cd music-restoration
./install.sh
```

Опционально — [Stereo Tool CLI](docs/stereo-tool.md): бесплатен для некоммерческого использования, в репозиторий не входит (лицензия не разрешает распространение), включает стадию панча ND2. Без него всё остальное работает: реставрация пойдёт в режиме `--nd2 0`.

## Типичный результат

Задавленные мастера 2000-х выходят из зоны войны громкости с сохранённым тембром: спектр в пределах ±1 дБ, true peak не выше −0.5 dBTP, ноль клиппинга, длительность совпадает до миллисекунды, DR вырастает примерно вдвое. Что означают эти числа — в [гайде по графикам](docs/graphs-guide.ru.md). Правило проекта: метрики ведут, но решают уши.

## Правовая заметка

Инструмент для музыки, которой вы владеете легально. Скрипты читают ваши файлы и пишут новые рядом — исходники не перезаписываются никогда. Сторонних бинарников в репозитории нет. Genius, lrclib, MusicBrainz и Cover Art Archive используются аккуратно: последовательные запросы и кэш.
