# music-restoration

Снять «войну громкости» со своей музыкальной библиотеки. Прозрачность — во
главе угла: пайплайн реставрации динамического диапазона (задавленные
мастера DR4–6 → DR8–12) с жёсткими шлюзами проверки, плюс уход за
библиотекой: тексты, обложки, теги, DR-сканирование — для локальных папок и
Android-телефона по MTP.

Основа — восстановленная по отпечатку профессиональная цепочка реставрации на
свободном софте (ffmpeg + numpy/scipy + бесплатные функции CLI Stereo Tool),
обкатанная на библиотеке ~3000 файлов, где каждая доставка проходит
md5-верифицированный шлюз.

**Два способа работы:**

1. **С ИИ-агентом** — `./install.sh` ставит четыре агентских скилла
   (`restore-dr`, `add-lyrics`, `phone-music`, `split-flac-album`); дальше
   просто просите агента: «реставрируй этот альбом», «добавь тексты в эту
   папку», «проверь телефонную библиотеку».
2. **Вручную** — обычные CLI-скрипты:

```bash
# диагноз задавленного мастера, затем реставрация трека
python3 restore-dr/scripts/diagnose.py album/*.flac
python3 restore-dr/scripts/master.py track in.flac out.flac

# одна команда на альбом: реставрация + обложки + теги + шлюз + заливка на телефон
python3 restore-dr/scripts/restore_batch.py "Исполнитель - Альбом" --lyrics --mb

# метрики, совпадающие с dr.loudness-war.info, и графики до/после
python3 restore-dr/scripts/measure.py compare in.flac out.flac --outdir report
python3 restore-dr/scripts/scan_dr.py            # DR-скан всей библиотеки
```

Ни одного захардкоженного пути: папка музыки на телефоне определяется сама
(gvfs MTP), локальная библиотека по умолчанию `~/Music`, рабочие файлы — в
`~/.local/state/music-restoration/`. Всё переопределяется через
`~/.config/music-restoration/config.env` или переменные окружения.

## Установка

```bash
git clone <этот репозиторий> && cd music-restoration
./install.sh
```

Зависимости: `python3` + `pip install -r requirements.txt`, пакеты
`ffmpeg flac metaflac curl gio`. Опционально:
[Stereo Tool CLI](docs/stereo-tool.md) (бесплатен для некоммерческого
использования, не входит в репозиторий — включает ND2-стадию панча).

## Типичный результат

Задавленные мастера 2000-х выходят из зоны войны громкости при сохранённом
тембре: спектр в пределах ±1 дБ, true peak ≤ −0.5 dBTP, ноль клиппинга,
длительность бит-в-бит, DR примерно вдвое выше. Что означают числа —
в [гайде по графикам](docs/graphs-guide.ru.md). Главное правило проекта:
**метрики ведут, но решают уши.**

## Правовая заметка

Инструмент для музыки, которой вы владеете легально. Скрипты читают ваши
файлы, пишут новые рядом (никогда поверх), сторонних бинарников не
содержат. Genius/lrclib/MusicBrainz/Cover Art Archive используются
аккуратно (последовательные запросы, кэш).
