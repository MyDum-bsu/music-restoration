# PRD — material-dependent constraints and release-level targets

Task: `t-20261114-230543-цель-материал-зависимые-ограничения-1347a5`
Evidence: `docs/eval-vs-masters-run.md` (Причины и улучшения, пункты 1–5).

## Goal

Close the systematic deviations the first master eval measured, without
re-introducing the unconditional processing the conservative runner removed:

1. True-peak ceiling follows the material class (quiet keeps −1.5, dense loud
   may use −0.3) instead of one number for everything — on quiet tracks we
   currently land up to 5.4 LU louder than masters.
2. The dynamics target comes from the release's own least-compressed third —
   killing the simultaneous undershoot (JP −0.94 DR) and overshoot
   (Junkie XL +1.60 DR) of the per-track constants.
3. Release loudness becomes an explicit, opt-in plan (`--loudness-target`)
   with a full re-QC, and `qc_gates` can enforce a LUFS window.
4. Punch (`spikes`/crest) is reported as headroom information, not defect.

## Non-goals

- Enabling `eq_match` (needs a master-corpus calibration curve — separate
  task), blind listening wiring, holdout corpus construction.
- Changing defaults for existing invocations: without the new flags and with
  identity/healthy classes, behavior is byte-identical to the previous runner
  except the class-conditional ceiling of dynamics candidates.

## Use cases

1. A quiet, sparse album: candidates run at −1.5 dBFS; the output stays far
   from any hot ceiling; masters' behavior (−4.3…−7.8 on quiet material)
   remains reachable by explicitly passing a lower `--loudness-target`.
2. A uniformly crushed album (median DR 5, best tracks DR 6): spread < 0.5 →
   class priors apply (no invention from noise).
3. An album with healthy bonus tracks (DR 11) among crushed ones: release
   target ≈ clamp(gap) replaces the crushed-class 5.3 constant.
4. Operator wants the release at −13 LUFS: `--loudness-target -13` — the pass
   gains under the plan ceiling and re-checks the encoded result.
