# release-restore: релиз от исходника до коллекции

Закрывает весь путь: проверить источник → разбить образ → реставрировать →
оформить (теги/обложка/тексты) → положить в коллекцию → отчитаться.

```bash
S=~/Desktop/projects/music-restoration/scripts
R=/media/mydum/Data/Music/restore

# 0. что за источник (DR, битность, настоящий ли lossless)
python3 $S/audio_measure.py "<каталог источника>"

# 1. если image+cue — разбить (скилл split-flac-album), образ убрать в _image/,
#    иначе он попадёт в обработку как отдельный трек

# 2. реставрация (цель берётся от модели, авто-политика по классу материала)
python3 $S/restore_one.py --src "<каталог с треками>" \
    --out "$R/release/<Artist> - <Album> (<год>) [restored]" \
    --auto-policy --adaptive --ml-snapshot auto --tp -0.5 --wait

# 3. оформление и копия в коллекцию
python3 $S/finish_release.py \
    --restored "$R/release/<Artist> - <Album> (<год>) [restored]" \
    --source   "<каталог источника>" \
    --dest     "$HOME/Music/restorations/<Artist> - <Album> (<год>) [restored]" \
    --lyrics
```

## Что делает каждый шаг

| шаг | инструмент | результат |
|---|---|---|
| проверка | `audio_measure.py` | DR, LUFS, TP, клиппинг, фейковый hi-res, lossy-транскод |
| разбиение | скилл `split-flac-album` | треки с тегами из cue |
| реставрация | `restore_one.py` | FLAC с поднятым DR, TP −0.5, отчёт `restore_report.jsonl` |
| оформление | `finish_release.py` | теги из источника, обложка, тексты, копия в коллекцию |
| тексты | скилл `add-lyrics` (вызывается из `finish_release`) | LYRICS в тегах |

## Ключевые решения

- **Цель берётся от модели** (`--ml-snapshot auto`), а не из классовой таблицы,
  но модель — уточнение: она зажата в ±2.5 дБ от класса и отключается
  OOD-гейтом. На незнакомом материале работает классовая таблица.
- **`--tp -0.5`** — привести true peak к −0.5 dBFS: у убитых мастерингов он
  часто выше 0 dBFS (интерсэмпловые пики), это слышно как жёсткость.
- **Один вариант — база, второй — тональный матч**: `--eq-curve corpus/tilt_curve.json
  --eq-match` добавляет замкнутый тильт-EQ (измеряет дельту полос и добирает
  разницу, до 3 итераций, капы 4 дБ ниже 100 Гц / 2 дБ выше). Делать как
  отдельную папку `[restored + tilt-match]`, чтобы можно было сравнить слепо.
- **Копировать, а не переносить** в коллекцию: в `release/` остаётся рабочая
  версия с отчётом.

## Грабли

- **`restore_one.py` отдаёт FLAC без тегов и обложек** — он про DSP. Без
  `finish_release.py` релиз выйдет «голым».
- **`metaflac` теряет многострочные тексты** при `--import-tags-from`
  («malformed vorbis comment field»). Перенос тегов в `finish_release.py` идёт
  через mutagen; повторный прогон оформления тексты не стирает.
- **`metaflac --import-picture-from` ДОБАВЛЯЕТ блок, а не заменяет** — при
  повторной вшивке нужно сначала снять старые (`--remove --block-type=PICTURE`).
  Опция `--dont-shuffle` есть не во всех сборках (1.4.3 её не знает).
- **Большие обложки раздувают каждый трек**: скан 3 МБ × 12 треков = 36 МБ
  лишнего. `finish_release.py` ужимает всё крупнее 400 КБ до 1200 px.
- **Обложки-фронта может не быть среди сканов** (только back/booklet/CD/inlay).
  Разворот буклета — обычно фронт в правой половине; вырезать и показать
  пользователю на подтверждение. Если он прислал свою — брать её.
- **Кавер-альбомы**: тексты не находятся по тегу исполнителя. Нужны оригинальные
  исполнители; если их нет в релизе (ни в буклете, ни на обложке, ни в
  MusicBrainz) — **спрашивать, а не угадывать**. Тексты каверов = тексты
  оригиналов.
- **Инструменталы**: на Genius страница есть, текста нет («page had no usable
  lyrics»). Это нормальный результат, а не ошибка — не подставлять чужой текст.
- **Имя трека в имени файла дублировалось** (`01. 01 Title.flac`) — в
  `restore_one.py` есть чистка префикса.
- **Место**: коллекция на `/home`, а он бывает заполнен под 95 %. Проверять
  `df -h /home` перед копированием пачки альбомов.
